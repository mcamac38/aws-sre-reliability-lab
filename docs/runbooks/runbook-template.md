\# Runbook Template



\## Issue



Describe the operational problem.



\## Symptoms



List what an operator would observe.



Examples:



\- Service unavailable

\- High HTTP 500 error rate

\- Unhealthy load balancer targets

\- ECS task failures

\- Kubernetes pods in CrashLoopBackOff



\## Detection



Explain how the issue is detected.



Examples:



\- CloudWatch alarm

\- Application logs

\- Load balancer health checks

\- Failed deployment verification



\## Immediate Response



Steps to stabilize the service.



\## Investigation Steps



Commands, dashboards, logs, or AWS console areas to inspect.



\## Recovery Steps



Actions to restore service.



\## Prevention



Changes that could reduce the chance of recurrence.



\## Related AWS Services



List relevant services.
