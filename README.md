\# AWS SRE Reliability Lab



This project is a hands-on Site Reliability Engineering lab built on AWS. The goal is to practice infrastructure as code, cloud reliability, observability, deployment automation, and failure recovery using Terraform, EC2, ECS, EKS, CloudWatch, and related AWS services.



\## Project Goals





\- Provision AWS infrastructure using Terraform.

\- Deploy a containerized application across EC2, ECS, and EKS.

\- Implement health checks, logging, monitoring, and alerting.

\- Practice controlled failure testing and recovery.

\- Document operational runbooks and incident response procedures.

\- Build portfolio evidence for Site Reliability Engineer and cloud infrastructure roles.





\## Current Phase 



Phase 0: AWS account access, Terraform authentication, project structure, Git setup, and documentation foundation.

Phase 1: EC2 deployment foundation.

Phase 2: ECS container deployment.

Phase 3: EKS Kubernetes deployment.

Phase 4: Observability, alarms, dashboards, and SLOs.

Phase 5: CI/CD, release safety, rollback, and failure testing.
